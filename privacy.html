Privacy policy

Channel Uploader. Last updated 17 November 2026.

YouTube API Services

Channel Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses it

Channel Uploader is used only by the owner of the YouTube channels listed on the home page, to manage those channels. It is not offered to the public, and it has no other users.

What it accesses and collects

With the owner's permission, given through Google's sign-in screen, it uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos to the owner's own channels and set their titles, descriptions, thumbnails, subtitles, playlists, categories and privacy;
  • post one comment from the channel on its own Shorts;
  • read the owner's own channels' details and statistics, such as video titles, views, likes, comment counts and watch time.

It does not access any other person's account or data, it does not collect personal information from viewers, and it does not use cookies or tracking.

How the data is used, kept and shared

Statistics are used only by the owner to decide which topics and formats to make next. The sign-in keys Google issues are stored privately, on the owner's computer and in the owner's private cloud workspace. Nothing is shared with, sold to or shown to anyone else, or used for advertising.

Channel Uploader's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

How long data is kept, and deletion

Statistics (views, likes, comment counts, watch time) are kept for up to 36 months for trend reports, as YouTube's policies allow. Other data from the API, such as video titles, is refreshed or deleted within 30 days. When access is withdrawn, the stored sign-in keys and all stored API data are deleted within 30 days.

Removing access

Access can be withdrawn at any time from the Google security settings page. Withdrawing it stops all further uploads and reads.

Contact

Questions about this policy can be sent through the contact details on any of the channels' YouTube pages.
